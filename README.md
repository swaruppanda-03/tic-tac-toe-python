**Tic-Tac-Toe in Python**

A simple two player tic-tac-toe game built using Python

Features
- Two player gameplay
- X and O turn switching
- Input validation
- Win and Draw detection
- Runs directly on the terminal
- 
*How to Run*

Make sure Python 3 is installed.

Clone the repository:
git clone https://github.com/YOUR-USERNAME/tic-tac-toe-python.git

Go into the project folder:
cd tic-tac-toe-python

Run the game:
python3 tic_tac_toe.py

*How to Play*

The board has 9 positions:

1 | 2 | 3 ---+---+--- 4 | 5 | 6 ---+---+--- 7 | 8 | 9


Players take turns entering a number from 1 to 9.

For example:
Player X, choose a position (1-9): 5
The player who gets three marks in a row wins.
